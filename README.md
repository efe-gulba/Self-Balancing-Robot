# Self-Balancing-Robot
This is a balance robot project developed using an IMU sensor and a PID control algorithm. The robot continuously measures its tilt angle, processes the sensor data and adjusts the motor speed to maintain its balance. 
# Hardware
- Arduino Uno
- MPU6050 Sensor
- DC motors
- TB6612FNG motor driver
- 9V battery
